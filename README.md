# Запуск

docker compose up -d
Сервис доступен на порте 8080

Также есть makefile (выполните make help)

# Стек
Go, БД `PostgreSQL`

Библиотека для миграций `goose`

Web-фреймворк `gin`

# Выполненные доп. задания

Эндпоинт статистики (доступен на /stats)

Нагрузочное тестирование (результаты в файле vegeta-report.txt, сам тест в /cmd/loadtest)

Метод массовой деактивации (/users/deactivateTeam, метод POST. У меня сработало за 17 мс на JSON с 200 users, лежащем в корне) и безопасная переназначаемость PR через транзакции

Unit-тестирование (в папке service)

Конфигурация линтера
